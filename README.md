# StudyFlow AI

A responsive AI-powered student study dashboard built with React, Vite, TypeScript, Tailwind CSS, and lucide-react.

## Run locally

```bash
npm install
npm run dev
```

## Included

- Responsive dashboard with desktop sidebar and mobile bottom navigation
- AI study assistant with persisted conversation history
- Subjects, smart notes, focus/Pomodoro timer, revision flashcards, exam planner, analytics, and profile settings
- Dark/light theme and localStorage persistence
- Realistic demo data, empty states, toasts, and functional interactions
